# 英雄联盟皮肤查询与下载 Web 服务 (LOL Skins Hub)

基于 **Fastify** 框架构建的高性能英雄联盟皮肤查询与下载 Web 服务。
资源源自开源项目 [Alban1911/LeagueSkins](https://github.com/Alban1911/LeagueSkins)。

## 🌟 核心特性

1. **智能英雄联想搜索**：
   - 支持英雄**中文名**（如“亚索”、“安妮”）、**官方称号**（如“疾风剑豪”、“黑暗之女”）。
   - 支持**拼音全拼**（“yasuo”、“anni”）与**拼音首字母简拼**（“ys”、“hazn”）。
   - 支持**常见玩家俗称/外号**（如输入“盲僧”精准匹配李青、“卡牌”匹配崔斯特、“剑圣”匹配易）。
   - 下拉联想框实时展示英雄头像、中英文信息与皮肤总数，支持键盘方向键与回车操作。

2. **全量皮肤展示与编号标注**：
   - 选中英雄后展示其所有皮肤与炫彩卡片。
   - 显著标注每个皮肤的**名称、编号（ID）、类型（原画/炫彩）、文件大小**。
   - 提供**常规皮肤 / 炫彩皮肤**分类过滤与英雄内部关键词次级筛选。

3. **纯内网环境自包含（服务端全代理）**：
   - 客户端前端页面**完全不引入任何外部字体文件与外部 CDN 样式/脚本**（纯原生自包含 CSS/JS，使用系统字体栈与内联 SVG 图标）。
   - 客户端无需访问 GitHub 或第三方数据站，所有皮肤预览图片与 `.fantome` / `.zip` 皮肤文件均由 Fastify 服务端进行安全代理与**本地磁盘持久化缓存**。

4. **北京时间（UTC+8）展示与服务端后台定时自动更新**：
   - 从源仓库 GitHub 提交记录精确抓取最后提交时间，并统一格式化为标准**北京时间（UTC+8）**在页面顶部显著展示。
   - 服务端内置轻量定时轮询任务，**每 1 小时自动检查一次 GitHub 变更**，一旦源仓库有新版本发布即自动在后台拉取并热更新本地数据，客户端无需也无法随意触发更新，保障内网稳定。

5. **智能缓存失效与版本感知（避免脏缓存）**：
   - **Git Blob SHA 校验**：基于 Git 底层哈希算法校验本地皮肤文件与源仓库的一致性，源仓库修改旧皮肤时自动识别差异并拉取最新文件，避免旧缓存残留。
   - **Data Dragon 版本隔离**：英雄头像与数据随 Riot Data Dragon 官方最新版本号动态隔离存储，官方美术重构或换代时自动平滑更新。

## 🚀 快速启动

### 环境要求
- Node.js >= 18.0.0 (推荐 v20 或 v22)
- npm >= 9.0.0

### 安装与运行

```bash
# 1. 安装依赖
npm install

# 2. 启动服务 (默认仅监听 127.0.0.1 本机回环，端口 3000)
npm start

# 备选：如需开放局域网访问
npm run start:lan

# 3. 运行自动化测试套件
npm test
```

启动成功后，在浏览器访问：
👉 `http://127.0.0.1:3000` 或 `http://localhost:3000`

## 📡 API 接口说明

| 接口地址 | 请求方式 | 说明 |
|---|---|---|
| `/api/info` | GET | 获取服务统计数据、版本与源仓库最后更新时间（北京时间） |
| `/api/champions` | GET | 获取全部 173 位英雄摘要列表，支持 `?q=关键词` 进行联想搜索 |
| `/api/champions/:key` | GET | 获取指定英雄（如 `157`）的全量皮肤列表与下载信息 |
| `/api/skins/download?path=...` | GET | 代理下载皮肤 `.fantome` 文件（自动附带文件名 Header） |
| `/api/proxy/champion-icon/:key` | GET | 代理并本地缓存英雄方形头像（PNG） |
| `/api/proxy/skin-image/:key/:skinId`| GET | 代理并本地缓存皮肤竖版立绘/加载图（JPEG/PNG） |
| `/api/tools/ltk-manager` | GET | 获取最新版本 LTK Manager 挂载工具发布信息（Tag、时间、资产列表） |
| `/api/tools/ltk-manager/download` | GET | 代理下载 LTK Manager 客户端安装包（EXE/MSI，服务端持久化缓存） |

> **注**：为保障内网与服务端安全，禁止客户端随意触发源仓库同步。如需更新底层皮肤数据，请在服务端执行 `npm run build:data`。

## 📂 目录结构

```text
lol-skins-download/
├── public/                    # 纯自包含前端单页面（无任何外部资源）
│   ├── index.html             # 网页结构与内联 SVG 图标
│   ├── style.css              # 原生 Hextech 蓝金质感样式表
│   └── app.js                 # 原生客户端交互、联想、过滤与下载
├── src/
│   ├── data/
│   │   └── catalog.json       # 预置 173 位英雄与 10,000+ 皮肤索引
│   ├── routes/
│   │   └── api.js             # Fastify RESTful API 路由
│   └── services/
│       ├── catalogService.js  # 目录索引、拼音权重检索与北京时间
│       └── proxyService.js    # 图片与 .fantome 文件服务端代理与磁盘缓存
├── scripts/
│   └── build-catalog.js       # 全量数据抓取与索引构建脚本
├── tests/
│   └── verify.js              # 自动化验证测试脚本 (8项全面验证)
├── cache/                     # 本地文件缓存（图片与皮肤文件）
├── server.js                  # Fastify 服务端入口
└── package.json               # 项目依赖与配置
```
